# Security Policy

## Supported versions

Yren Personal OS is currently in early development and has no stable release. Security fixes are applied to the latest public `main` branch unless a release note states otherwise.

## Reporting a vulnerability

Do not publish secrets, credentials, personal data, exploit details, or sensitive logs in a public issue or pull request.

Use GitHub private vulnerability reporting when it is available for this repository. If that option is unavailable, open a minimal public issue asking for a private reporting channel and omit all sensitive technical details.

A useful report should include:

- the affected component and revision;
- the expected and observed behavior;
- clear reproduction steps using non-sensitive test data;
- the potential impact;
- any temporary mitigation already identified.

## Public repository boundary

This repository must not contain real credentials, private keys, personal records, production databases, backups, private logs, AI memory, local machine identifiers, private planning documents, or unlicensed third-party assets.

Examples and tests must use fictional, synthetic, anonymized, or fully redacted data.

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure. No specific response or resolution deadline is guaranteed while the project remains pre-release.
