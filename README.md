# Yren Personal OS

Yren Personal OS is an early-stage, local-first personal AI workstation for organizing projects, tasks, knowledge, and AI-assisted creative workflows.

## Privacy boundary

This public repository contains only approved source code, public documentation, example configuration, fictional or anonymized test data, and redacted technical evidence.

It must not contain secrets, credentials, personal data, production databases, backups, private logs, AI memory, personal plans, internal governance records, or unlicensed third-party assets.

## Project status

The project is in early foundation and architecture qualification. Interfaces, implementation details, and repository structure may change before the first stable release.

## Internal documentation

Detailed product decisions, internal roadmaps, risk records, incident reports, and project-governance materials are maintained separately and are not part of this public repository.
